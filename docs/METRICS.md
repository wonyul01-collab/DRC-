# 지표 정의서

리포트의 모든 숫자가 어떻게 나오는지. 해석에 이견이 생기면 이 문서를 기준으로 한다.

---

## 매출을 두 가지로 나누는 이유

| 지표 | 정의 | 출처 |
|---|---|---|
| **전환매출** (`conv_value`) | 광고 채널이 자기 어트리뷰션 창으로 잡은 매출 | 각 광고 채널 리포트 |
| **실매출** (`realized_sales`) | 정산 기준 확정 매출 | 판매채널 주문 데이터 |

```
실매출 = 순매출(net_sales) − 취소 − 반품
```

각 광고 채널은 **같은 주문을 각자 자기 공으로 계산한다.** 고객이 인스타
광고를 보고, 네이버에 브랜드명을 검색해 들어와 샀다면 그 주문 하나가
메타와 네이버 양쪽에 잡힌다. 그래서 채널 전환매출의 합은 실매출보다
항상 크다.

리포트의 `attribution_gap`이 그 괴리율이다.

```
어트리뷰션 괴리율 = (전환매출 합 − 실매출) ÷ 실매출
```

**수익성 판단은 언제나 실매출 기준이다.** 전환매출은 채널 간 상대 비교에만 쓴다.

---

## 손익분기 ROAS

리포트에서 가장 중요한 숫자다. 광고의 성패를 절대값이 아니라 이 기준선
대비로 판정한다.

```
매출총이익률 = (판매가 − 매입원가) ÷ 판매가
공헌이익률   = 매출총이익률 − 채널수수료율
손익분기 ROAS = 1 ÷ 공헌이익률
```

**유도:** 매출 R, 광고비 A일 때
공헌이익 = R × 공헌이익률 − A. 이것이 0이 되는 지점이 손익분기이므로
R ÷ A = 1 ÷ 공헌이익률.

### 예시

스마트스토어, 마진율 45%, 수수료 5.85%:

```
공헌이익률 = 0.45 − 0.0585 = 0.3915
손익분기 ROAS = 1 ÷ 0.3915 = 255%
```

이 채널에서 **ROAS 250%는 적자**다. "ROAS 300% 나왔으니 잘했다"는 판단이
왜 위험한지가 여기 있다 — 쿠팡(수수료 10.8%)에서는 손익분기가 292%라
같은 300%가 거의 본전이다.

매출총이익률은 카탈로그에 원가가 있는 SKU의 **실제 판매 구성비로 가중평균**한다.
원가가 없는 SKU는 `default_gross_margin_rate`로 대체하되, `doctor`가
그 개수를 경고한다.

---

## 공헌이익

```
공헌이익 = 실매출 × (매출총이익률 − 채널수수료율) − 광고비
```

고정비(인건비·임대료 등)는 반영하지 않는다. 이 리포트는 **광고 의사결정용**이고,
광고를 늘리고 줄이는 판단에는 고정비가 영향을 주지 않기 때문이다.

---

## 채널 판정 기준

| 판정 | 조건 | 의미 |
|---|---|---|
| 증액검토 | ROAS ≥ 손익분기 × 1.3 | 여유가 있어 예산 증액 가능 |
| 유지 | ROAS ≥ 손익분기 | 흑자이나 여유는 적음 |
| 개선필요 | ROAS ≥ 손익분기 × 0.7 | 적자. 개선 여지 있음 |
| 즉시축소 | ROAS < 손익분기 × 0.7 | 손실이 큼 |
| 전환없음 | 전환 0인데 지출 발생 | 즉시 점검 |
| 마진구조점검 | 수수료 > 마진율 | 광고 이전에 상품 구조 문제 |

## 낭비 키워드 판정 규칙

**공통 전제 — 표본 하한.** 클릭 `min_clicks`(기본 20) 미만이거나
광고비 `min_cost`(기본 3만원) 미만인 키워드는 **판정하지 않는다.**
클릭 3회에 전환 0이라고 끄면 멀쩡한 키워드를 계속 죽이게 된다.

| 규칙 | 조건 | 등급 | 절감 추정 |
|---|---|---|---|
| `zero_conversion_spend` | 전환 0 + 표본 충족 | 긴급 | 지출 전액 |
| `below_breakeven_roas` | ROAS < 손익분기 | 긴급/높음 | 손익분기 초과 지출분 |
| `high_cpc_low_cvr` | CPC > 채널중앙×1.8 **그리고** CVR < 채널중앙×0.5 | 보통 | 정상 CPC 초과분 |
| `brand_cannibalization` | 설정된 브랜드 키워드 | 보통 | 지출의 50% |

기준을 **채널 내 중앙값 대비 상대값**으로 잡는 이유: 채널마다 CPC 수준이
원래 다르다. 절대 기준(예: CPC 2000원 이상)을 쓰면 특정 채널만 계속 걸린다.

절감 추정액은 조회 기간 실적을 **30일로 환산**한 값이다.

## 제외키워드 vs 승격 후보

둘 다 **검색어 리포트**에서만 나온다. 등록 키워드 데이터로는 산출 불가능하다.

- **제외키워드 후보** — 전환 0이면서 비용이 발생한 실제 검색어.
  개별 키워드를 끄는 것보다 절감 효과가 크다. 하나의 광범위 키워드가
  수십 개의 무관한 검색어를 끌어오기 때문이다.

- **승격 후보** — 전환 2건 이상인데 개별 키워드로 등록되지 않은 검색어.
  광범위 매칭에 묻혀 있어 전용 입찰가를 줄 수 없는 상태다. **낭비 제거만
  하면 매출도 같이 줄어들기 때문에** 이쪽이 반드시 함께 있어야 한다.

## 매출 증감 요인분해

매출을 세 요소의 곱으로 본다.

```
매출 = 트래픽 × 전환율 × 객단가
```

직전 동기간 대비 변동을 순차 치환으로 분해한다.

```
기준        = 트래픽ₚ × 전환율ₚ × 객단가ₚ
트래픽 효과 = 트래픽ᶜ × 전환율ₚ × 객단가ₚ − 기준
전환율 효과 = 트래픽ᶜ × 전환율ᶜ × 객단가ₚ − 직전값
객단가 효과 = 트래픽ᶜ × 전환율ᶜ × 객단가ᶜ − 직전값
```

절대값이 가장 큰 것이 주원인이며, 처방이 완전히 다르다:

| 주원인 | 처방 |
|---|---|
| 트래픽 | 입찰가·예산·신규 키워드 확대 |
| 전환율 | 상세페이지·가격경쟁력·리뷰 |
| 객단가 | 할인율 과다, 저가 구성 편중 |

"매출이 20% 빠졌다"만으로는 아무 조치도 할 수 없다는 것이 이 분해의 이유다.

## 예산 재배분 시뮬레이션

1. 손익분기 미달 채널에서 **손익분기를 맞추는 수준까지만** 회수
   (`회수액 = 광고비 − 전환매출 ÷ 손익분기ROAS`)
2. 손익분기 1.2배 이상 채널로 **여유도 비중대로** 배분
3. 한 채널에 현재 예산의 **50%를 넘겨 증액하지 않는다**
4. 기대 추가매출에 **효율 체감 30%**를 반영

```
기대 추가매출 = 이동액 × 현재ROAS × 0.7
```

체감을 반영하지 않으면 시뮬레이션이 항상 장밋빛으로 나온다. 실제로는
증액할수록 한계 효율이 떨어진다. **이 값은 추정치이며 확정 수치가 아니다.**

---

## CAC 회수 주문수 (자사몰)

```
CAC = 광고비 ÷ 신규 주문수
첫주문 공헌이익 = 객단가 × 공헌이익률
CAC 회수 주문수 = CAC ÷ 첫주문 공헌이익
```

이 값이 **1을 넘으면 재구매 없이는 신규 획득이 적자**라는 뜻이다.
광고비는 대부분 신규 획득에 쓰이는데 성과는 전체 매출로 평가하면,
재구매가 만든 매출까지 광고 공으로 잡혀 ROAS가 부풀려진다.

---

## 데이터 결손 처리

리포트는 매번 최근 7일의 채널별 데이터 존재 여부를 점검하고, 결손을
**최상단 경고로** 표시한다.

결손을 숨기면 "광고비 0원 = 효율 무한대" 같은 결론이 나온다. 데이터가
안 들어온 것과 실제로 0인 것은 완전히 다르다.
