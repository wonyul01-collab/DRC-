# 파일럿 EP01 대본 — 성분언니

**제목(안)**
- A: 올리브영 주름 크림, 광고 말고 '이 표시' 하나만 보세요
- B: 주름 화장품 5만원 쓰기 전에 성분표부터 보세요 | 40대 올리브영 고르는 법
- C: "바르는 보톡스"는 없습니다. 대신 이 4가지 성분을 찾으세요

**길이** 약 9분 / **타깃** 40~60대 노화 고민 / **캐릭터** SungbunUnni_v1 (AI 캐릭터)

**썸네일**: 캐릭터가 크림통을 의심스럽게 들고 있는 컷(학습사진 #17 톤) + 큰 글씨 "이 표시 없으면 패스"

## 기본 원칙 (편집·검수용)
- 이번 편은 **특정 제품을 추천하지 않고 '고르는 법'** 을 알려주는 편. 제품 컷은 라벨을 가리거나 안 보이게.
  → 제품을 실제로 사서 성분표를 확인하기 전까지 제품명을 말하지 않는다.
- 금지 표현: 보톡스 효과, 주름이 없어진다, 치료, 재생, 시술 대신, 100%.
- 허용 표현: "주름 개선에 도움을 주는 기능성 화장품" (식약처 심사·보고된 문구 범위)
- 🔎 표시 = 업로드 전 사람이 공식 출처로 다시 확인할 문장.

### #4 성분 4가지 (2:00–6:00)
도입 (2:00) — "주름 개선 기능성으로 식약처가 고시한 성분은 네 가지예요. 이것만 외우세요." 🔎
그래픽: 4칸 카드 (레티놀 / 레티닐팔미테이트 / 아데노신 / 폴리에톡실레이티드레틴아마이드)

**① 레티놀 (2:20–3:20)**
- "제일 유명하죠, 레티놀. 비타민 A 계열이에요."
- "효과 기대가 큰 만큼, 처음엔 따갑거나 각질이 일어날 수 있어요. 그래서 처음엔 이틀에 한 번, 밤에만, 소량부터."
- "햇빛에 약해서 밤에 바르고, 다음 날 아침엔 선크림 꼭이요."
- "임신 중이거나 계획 중이시면 레티놀 계열은 의사와 먼저 상담하세요." 🔎
- 화면: 저녁 조명 이마에 크림 바르는 컷(#12 톤), 달력 그래픽 '월·수·금'

**② 레티닐팔미테이트 (3:20–4:05)**
- "이건 레티놀의 순한 사촌이라고 보시면 돼요. 피부에서 천천히 바뀌어서 자극이 덜한 편이에요." 🔎
- "레티놀이 부담스러운 분, 처음 시작하는 분께 맞아요."
- 화면: 크림 텍스처 매크로 B-roll

**③ 아데노신 (4:05–4:50)**
- "아데노신은 아마 제일 많이 보셨을 거예요. 주름 기능성 제품에 정말 흔하게 들어가요."
- "자극이 적어서 아침저녁 다 쓰기 편해요. 대신 기대치는 '순하게 꾸준히' 쪽이에요."
- 화면: 아침 욕실 토너 컷(#6 톤)

**④ 폴리에톡실레이티드레틴아마이드 (4:50–5:30)**
- "이름이 제일 어렵죠. 성분표에서 '레틴아마이드'가 보이면 이거예요."
- "자주 보이는 성분은 아니라서, 이런 게 있다는 것만 알아두셔도 돼요."
- 화면: 성분표 위에 형광펜 그래픽

**정리 (5:30–6:00)**
- "정리하면, 센 거 원하면 레티놀, 순하게 시작하려면 레티닐팔미테이트나 아데노신."
- 그래픽: 강도 막대 (레티놀 > 레티닐팔미테이트 ≥ 아데노신) — "개인차 있음" 표기
