### VLOG 컷 만드는 법 (2026-10-28 A/B 검증 — handheld 우세)
- 모델 Seedance 2.5 omni_reference, 16:9, 720p, 15초(105크레딧). 참조 = 서윤 정면 사진(T1).
- 프롬프트는 반드시 `Handheld vlog` 로 시작. 서윤은 **말하지 않는다**(목소리는 서현 내레이션). 브랜드 없는 흰 튜브. 생활 소리(두드림·창밖)만.
- 한 클립을 두 장면에 나눠 쓴다: 앞부분 = VLOG 전체 화면, 뒷부분 = USAGE 폴라로이드 안 영상(`img.vlog data-off`).
- 렌더 엔진은 영상을 30fps JPG 시퀀스(`img/vlog/0001.jpg`)로 풀어 프레임마다 바꿔 끼운다(헤드리스 크롬 H.264 재생 문제 회피). 생활 소리는 ffmpeg 로 내레이션 밑에 섞는다.
- 제품을 "써봤다"는 표현 금지 규칙(3-7)은 VLOG 에도 그대로. 클립은 "연출"이라고 표기한다.

## 3. 이미지·정보 사용 규칙 (A 방식)

1. 제품 이미지는 **브랜드 공식몰** 이미지만 쓴다. 올리브영 등 유통사 이미지는 쓰지 않는다(자동 접속 차단 + 권리 불명확).
2. 장면마다 출처를 표기한다: `이미지 출처: ○○ 공식몰`, 정보 장면은 `· YYYY.MM 확인` 추가.
3. 이미지는 설명에 필요한 만큼만 쓴다. 상세페이지 광고 문구(어워드 배지, "어린주름" 스티커 등)는 잘라낸다.
4. 브랜드가 사용 중단을 요청하면 즉시 해당 영상 비공개 → 이미지 교체 후 재업로드.
5. 성분·기능성·가격은 **공식 상품정보 표(상품정보제공고시)** 에서만 가져온다. 해외 판매처·블로그 정보 사용 금지.
6. 말할 수 있는 것: 표시 사실(기능성 여부, 함량, 성분 유무, 정가). 말하면 안 되는 것: "효과 없다/좋다", "보톡스", "치료", 다른 제품 비하.
7. AI 캐릭터는 제품을 "써봤다"고 말하지 않는다(거짓 후기). 텍스처는 "공식 이미지"로만 보여준다. 직접 촬영(B→A 전환)은 사람이 실제 사용한 경우에만 후기 표현 허용.
8. 내돈내산이 아닌 제휴 링크가 들어가면 설명란 첫 줄과 영상 첫 장면에 광고 표시.

## 4. 제작 순서

1. 주제·제품 선정 → 공식몰에서 상품정보 표(기능성 여부·전성분·용량·정가) 확인, `sources.md` 기록
2. 대본 6~40문장 작성 (1문장 = 1장면, 장면 코드 지정) → 사람 검수(금지 표현, 출처)
3. `engine/tts.sh` 로 서현 음성 생성 → 문장 길이 자동 측정(`dur.js`)
4. 이미지 준비: 공식몰 이미지 다운로드 → 흰 배경 제거(`magick -fuzz 2% floodfill`) → 컷아웃
5. `engine/index.html` 장면 복제·문구 교체 → 정지 화면 확인(`cap.js real 6.5,20,...`)
6. `engine/rend.sh` 로 렌더(1분당 약 6분) → 업로드
7. 업로드 체크: 유튜브 "변경되거나 합성된 콘텐츠: 예", 설명란 AI 고지·출처·확인일
