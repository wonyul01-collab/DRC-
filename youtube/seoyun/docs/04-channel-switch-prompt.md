# 채널 전환 — PC 클로드에 붙여넣을 작업 지시문

클라우드 세션은 유튜브 스튜디오에 로그인할 수 없다. 그래서 이 작업은 **구글에 로그인된 PC의
Claude 데스크톱 앱**(Claude in Chrome 켜진 상태)에서 돌린다. 아래 박스 전체를 복사해 한 번에 붙여넣는다.

```
유튜브 스튜디오에서 내가 안 쓰는 기존 채널 하나를 「서윤의 성분노트」 채널로 바꿔줘. Chrome 확장(Claude in Chrome)으로 직접 진행해.
기준 문서: https://github.com/wonyul01-collab/DRC-/blob/claude/ai-influencer-cosmetics-youtube-7cbpyd/youtube/seoyun/docs/03-channel-kit.md
순서:
1) https://www.youtube.com/account 에서 내 채널 목록을 보여주고, 영상이 거의 없거나 오래 안 쓴 채널 후보를 골라 나에게 어느 채널로 할지 한 번만 물어봐. (차계부·말랑한툰·미담한스푼·명문사주·거인의결단 등 운영 중인 채널은 제외)
2) 고른 채널로 전환한 뒤 https://studio.youtube.com 에서 채널 관리 → 경고(스트라이크)가 있는지 확인. 있으면 멈추고 알려줘.
3) 기존 공개 영상은 삭제하지 말고 전부 '비공개'로 바꿔. 바꾸기 전에 영상 개수와 제목 목록을 보여주고 확인받아.
4) 맞춤설정 → 브랜딩: 프로필 사진·배너를 기준 문서 1번 링크의 이미지로 교체 (먼저 내려받아서 업로드).
5) 맞춤설정 → 기본 정보: 이름 「서윤의 성분노트」, 핸들은 @seoyun_note → 안 되면 @seoyunnote → @seoyun.ai 순서로, 설명은 기준 문서 3번 그대로, 문의 이메일은 비워 두고 나에게 물어봐. 이름·핸들은 바꾸기 직전에 한 번 확인받아(변경 횟수 제한).
6) 설정 → 채널 → 키워드에 기준 문서 4번, 설정 → 업로드 기본설정에 카테고리 '노하우/스타일', 언어 한국어, 설명 기본값에 AI 고지 3줄.
7) 재생목록 4개(기준 문서 5번)를 공개 범위 '공개'로 만들어 둬.
8) 끝나면 바뀐 항목 표와 채널 주소(링크)를 보고해. 비밀번호나 인증 코드가 필요하면 내가 직접 입력하게 멈춰.
```
