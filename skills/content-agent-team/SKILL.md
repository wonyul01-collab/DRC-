# 콘텐츠 에이전트팀 — 소재·카피 초안 제작

`ad-daily-report`/`ad-monthly-close`가 "무엇이 문제인지"를 숫자로
찾아내면, 이 스킬은 그중 **콘텐츠·소재로 풀 수 있는 문제**를 골라
실제로 쓸 수 있는 카피·구성 초안을 만든다. 입찰가·예산 조정처럼
숫자로 푸는 문제는 이 스킬의 범위가 아니다 — 그건 두 리포트 스킬이
이미 처방한다.

## 역할 분담 — 반드시 지킬 것

**여전히 숫자는 `adops`가 계산한다.** 이 스킬은 `adops` 브리프에 이미
있는 판정(전환없음, 광고 사각지대, 신상품 등)을 **입력**으로만 쓰고,
ROAS·손익분기·공헌이익 같은 지표를 스스로 다시 계산하거나 언급하지
않는다. 콘텐츠 초안에 숫자를 넣어야 하면 브리프에서 그대로 인용한다.

**대외비 수치는 산출물에 절대 넣지 않는다.** `config/config.yaml`의
`channel_fees`(수수료율), `catalog.csv`의 `원가`는 카피에 등장할 이유가
없다. 상품명·판매가·카테고리처럼 대외에 공개돼도 되는 정보만 쓴다.

**실제 채널 업로드·집행은 하지 않는다.** 이 스킬의 산출물은 항상
사람의 승인을 기다리는 **초안**이다. 메타/인스타/버퍼 등에 자동
게시하는 기능이 붙어 있더라도, 이 스킬 안에서는 쓰지 않는다. 광고
소재 자동 재집행은 아직 리스크가 크다는 것이 이 방법론의 전제다
([`docs/MARKETING_AGENT_GUIDE.md`](https://github.com/wonyul01-collab/DRC-/blob/main/docs/MARKETING_AGENT_GUIDE.md) 참고).

## 언제 쓰나

- `ad-daily-report`의 `조치대기열`이나 `판매채널.판정`에 소재·콘텐츠로
  해결 가능한 항목이 있을 때 (예: 노출은 있는데 전환이 없음 → 상세
  페이지 카피 문제일 수 있음)
- `ad-monthly-close`의 **광고 사각지대**(잘 팔리는데 광고가 안 붙은
  상품)가 발견됐을 때 — 그 상품의 광고 소재가 아직 없다는 뜻
- 신상품 출시, 시즌 프로모션 등 처음부터 콘텐츠가 필요할 때
- 사용자가 특정 상품·주제를 직접 지정했을 때 (adops 신호 없이도 실행 가능)

**쓰지 않는 경우:** 입찰가·예산·제외키워드처럼 숫자로 바로 처방되는
문제. 그건 `ad-daily-report`가 이미 한다.

## 절차

### 1단계 — 입력 신호 확보 (리서치)

adops 신호로 시작하는 경우:

```bash
cd "$ADOPS_HOME"
cat "out/brief-daily-$(date -d yesterday +%F).json"
```

브리프에서 다음을 훑어 **콘텐츠로 풀 수 있는 항목**만 추린다:
- `조치대기열`에서 "전환없음", "소재", "상세페이지" 같은 사유가 붙은 항목
- `광고 사각지대` 목록 (README의 매출 반등 레버 항목)
- `판매채널.판정`이 `개선필요`인데 원인이 트래픽이 아니라 전환율인 상품
  (`매출요인분해` 참고 — 트래픽 문제면 이 스킬 대상이 아니다)

사용자가 주제를 직접 준 경우 이 단계는 생략하고 2단계로 간다.

상품 상세 정보는 카탈로그에서 가져온다. **원가 컬럼은 읽지도, 인용하지도
않는다:**
```bash
python3 -c "
import csv
with open('data/raw/catalog/catalog.csv', encoding='utf-8-sig') as f:
    for row in csv.DictReader(f):
        if row['sku'] == '대상SKU':
            print(row['상품명'], row['판매가'], row['카테고리'])
"
```

### 2단계 — 기획·전략

아래를 확정하고 사용자(또는 스스로)에게 한 줄로 정리해 보여준다:

- **형식**: 인스타 카드뉴스 / 상세페이지 카피 / SNS 캡션 / 광고 헤드카피
  중 상황에 맞는 것. 여러 개를 동시에 만들어도 된다.
- **타깃 키워드**: adops 브리프의 `핵심키워드추세`나 사용자가 지정한 것
- **핵심 메시지**: 이 콘텐츠 하나로 전달할 단 하나의 주장
- **CTA**: 구매/방문/저장 중 무엇을 유도할지

### 3단계 — 카피·구성 초안

형식별로 실제 문안을 쓴다. **한 번에 최종안 하나만 내지 말고 2~3개
버전(톤·훅이 다른 것)을 만든다** — 영상에서 강조하듯 AI는 맥락 없는
신입과 같아서 처음부터 완벽을 기대하기 어렵다. 여러 버전을 만들고
사람이 고르거나 다듬게 하는 편이 실무적으로 낫다.

카드뉴스처럼 이미지가 필요한 형식은, 이미지 생성 커넥터/스킬이 별도로
붙어 있을 때만 실물을 만든다. 없으면 **디자인 브리프**(장표 수, 각
장의 문구, 레이아웃 지시)까지만 작성하고 실제 디자인은 사람이나
디자인 도구(캔바 등)에 넘긴다. 없는 도구를 있다고 가정하고 진행하지
않는다.

### 4단계 — 자체 검수

산출물을 넘기기 전에 아래를 스스로 점검한다:

- [ ] 대외비 수치(원가, 수수료율, 내부 목표치)가 하나도 없다
- [ ] 표시·광고법상 과장 표현("최고", "완치", "1위" 등 근거 없는 단정)이 없다
- [ ] 경쟁사를 직접 비방·비교하는 표현이 없다
- [ ] adops 브리프에서 인용한 숫자는 브리프 표현 그대로다 (재계산 없음)
- [ ] 오탈자·비문이 없다
- [ ] CTA가 명확하다

### 5단계 — 저장

**저장소 안에만 쓴다.** `/tmp` 등 밖에 쓰면 `HERMES_WRITE_SAFE_ROOT`
제약으로 조용히 거부된다.

```
$ADOPS_HOME/out/content-<날짜>-<slug>.md
```

사람이 검토·승인한 뒤에만 실제 채널에 올라간다. 이 스킬은 여기서
끝난다.

### 6단계 — 피드백 루프 (다음 실행 때)

발행 며칠 뒤 `ad-daily-report`가 해당 상품의 전환율 변화를 이미
보여준다. 반응이 낮았다면 다음 실행 때 메시지·훅을 바꿔서 다시
시도한다 — 한 번 시도로 판단하지 않는다.

## 함정

- **원가·수수료율을 "설명을 위해" 잠깐이라도 카피에 옮기지 마라.**
  초안이라도 저장소 밖(메일, SNS 예약함)으로 나가는 순간 통제할 수 없다.

- **adops 신호 없이 감으로 소재를 대량 생산하지 마라.** 이 스킬은
  숫자가 짚어준 문제를 풀 때 가장 값어치가 있다. 신호 없이 만들면
  그냥 콘텐츠 생산 도구일 뿐, "매출을 올리는" 루프가 아니다.

- **버전 하나 보고 실망해서 멈추지 마라.** 첫 결과물은 대체로 평균적이다.
  맥락(브랜드 톤, 과거에 잘됐던 카피 예시)을 더 주고 다시 시켜라.

- **이미지 생성 도구가 없는데 있는 척 결과를 지어내지 마라.** 디자인
  브리프로 대체하고, 실물이 필요하면 사람에게 명시적으로 알린다.

- **자동 게시로 이어붙이지 마라.** 버퍼·메타 MCP 같은 발행 자동화는
  영상에서도 소개됐지만, 사람 승인 없는 자동 게시는 이 스킬의 범위
  밖이다. 잘못된 카피가 그대로 나가는 사고를 막기 위한 경계다.

## 검증

산출물을 넘기기 전 확인한다:

- [ ] 입력이 adops 브리프의 실제 항목이거나, 사용자가 명시한 주제다 (근거 없음)
- [ ] 2단계 이상 버전이 있다
- [ ] 4단계 검수 체크리스트를 통과했다
- [ ] 파일이 `$ADOPS_HOME/out/` 안에 **실제로 존재한다** (`ls -l`로 확인)
- [ ] "이것은 초안이며 승인 전 게시되지 않았다"는 문구가 산출물 상단에 있다
