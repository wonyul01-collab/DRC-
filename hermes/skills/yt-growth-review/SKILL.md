# 주간 성과 리뷰

숫자를 보고 **다음 주에 무엇을 바꿀지** 한 가지로 좁힌다. 리포트 자체가 목적이 아니다.

## 데이터 수집

```bash
python {scripts_dir}/youtube_analytics.py channel --days 28
python {scripts_dir}/youtube_analytics.py videos  --days 28 --limit 20
python {scripts_dir}/youtube_analytics.py traffic --days 28
```

`{output_dir}/log.jsonl` 의 제작 기록과 대조해, 어떤 기획 각도가 어떤 성과로 이어졌는지 연결한다.

## 판정 기준

쇼츠는 **평균 시청 지속률(`averageViewPercentage`)** 이 1차 지표다. 조회수는 결과일 뿐이다.

| 신호 | 해석 | 조치 |
|---|---|---|
| 지속률 낮고 조회수 낮음 | 훅 실패 | 첫 2초를 다시 쓴다 |
| 지속률 낮고 조회수 높음 | 제목/썸네일이 내용보다 앞섬 | 낚시 줄이고 본문 밀도 올린다 |
| 지속률 높고 조회수 낮음 | 소재 수요 부족 | 같은 포맷, 다른 소재 |
| 지속률 높고 조회수 높음 | 성공 패턴 | 이 각도를 변주해 3편 더 |
| 구독 전환 낮음 | 채널 정체성 불명확 | 캐릭터·포맷 고정 |

## 수익화 진행 점검

브리프의 목표에 맞춰 현재 위치를 명시한다.

- **YouTube 파트너 프로그램(광고 수익)**: 구독자 및 시청시간 요건까지 남은 수치를 계산해 보고한다.
  요건은 바뀔 수 있으니 확정 수치가 필요하면 공식 문서를 확인하고 출처를 남긴다.
- **상품 판매(본선)**: 광고 수익보다 이쪽이 빠르다. 아래를 매주 확인한다.
  - 영상 → 설명란 링크 → 랜딩 → 전환, 각 단계에서 어디가 새는가
  - 상위 조회수 영상의 CTA 가 상품과 실제로 이어져 있는가
  - 리드(이메일/오픈채팅) 유입 수가 조회수와 함께 늘고 있는가

## 출력

`{output_dir}/reviews/YYYY-MM-DD.md` 에 저장하고, 대화로는 아래만 짧게 보고한다.

1. 이번 주 숫자 3줄
2. 먹힌 것 하나 / 안 먹힌 것 하나 (근거 영상 ID 포함)
3. **다음 주에 바꿀 것 딱 한 가지**
4. 다음 주 기획 요청: `yt-trend-research` 에 넘길 방향 한 문장

## 하지 말 것

- 표본이 부족한데(영상 3편 미만, 기간 7일 미만) 단정적으로 결론 내지 않는다. "아직 판단 불가"라고 쓴다.
- 매주 방향을 통째로 바꾸지 않는다. 한 번에 한 변수만 바꿔야 무엇이 효과였는지 알 수 있다.
