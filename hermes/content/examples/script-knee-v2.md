# 대본 예시 — 계단 내려갈 때 무릎 하중 (2차 개정)

첫 대본이 "사전을 읽어주는" 느낌이라 다시 썼습니다.
**무엇이 달라졌는지** 를 보여주는 것이 이 파일의 목적입니다.
새 대본을 쓸 때 이 구조를 참고하세요.

## 1차와 2차의 차이

| | 1차 (버림) | 2차 (이 문서) |
|---|---|---|
| 첫 문장 | "계단 한 칸. 무릎엔 몇 kg?" | "등산 갔다 내려올 때, 유독 무릎이 시큰했던 적 있으시죠?" |
| 시작점 | 숫자 | **경험** |
| 숫자 위치 | 처음부터 끝까지 | 중반 이후에만 |
| 마무리 | "내려가는 게 더 힘든 이유입니다" | 일상으로 복귀 — 오늘 어디서 몇 번 |
| 화면 | 인체 모델 4컷 | **스톡 실사 6컷 + 몸 속 1컷** |
| 길이 | 27.8초 | 대본 52초 → 1.1배속 → **47초** |
| 크레딧 | 110cr | **28cr** |

1차는 사실 전달이고, 2차는 **시청자가 자기 무릎을 떠올리게** 만듭니다.
같은 논문, 같은 숫자입니다. 순서만 바꿨습니다.

---

## 2차 대본

### 경험 (0~12초) — 숫자를 쓰지 않는다

| 시간 | 나레이션 | 화면 |
|---|---|---|
| 0~4 | "등산 갔다 내려올 때, 유독 무릎이 시큰했던 적 있으시죠?" | **스톡** 하산하는 등산객 뒷모습 |
| 4~8 | "올라갈 때는 멀쩡했는데 말입니다." | **스톡** 오르막을 오르는 장면 |
| 8~12 | "이상하죠. 힘든 건 분명 올라갈 때인데." | **스톡** 숨 고르는 등산객 |

자막: `등산 갔다 내려올 때` / `무릎이 시큰했던 적` / `올라갈 때는 멀쩡했는데`

### 설명 (12~38초) — 여기서 처음 숫자가 나온다

| 시간 | 나레이션 | 화면 |
|---|---|---|
| 12~17 | "무릎에 실리는 무게를 실제로 재본 연구가 있습니다." | **스톡** 계단 오르내리는 발 클로즈업 |
| 17~23 | "평지를 걸을 때가 체중의 261%." | **AI ★** 몸 속 무릎 — 옅은 주황 |
| 23~29 | "계단을 오를 때는 316%." | **AI ★** 같은 클립, 주황이 짙어짐 |
| 29~33 | "그럼 내려올 때는 얼마일까요." | **스톡** 계단 위에서 아래를 내려다보는 시점 |
| 33~38 | "346%. 오를 때보다 무겁습니다." | **AI ★** 무릎이 붉게 달아오름 |

- 강조: `261%` `316%` **`346%`**
- 보조 자막: 17초 구간에 `체중 70kg 기준`, 33초 구간에 `계측 인공관절 5명 측정값`

### 일상 복귀 (38~52초) — 다시 구체적인 장소로

| 시간 | 나레이션 | 화면 |
|---|---|---|
| 38~43 | "지하철 출구 계단, 아파트 현관, 등산로 하산길." | **스톡** 지하철 계단 |
| 43~48 | "우리는 하루에도 수백 번 내려갑니다." | **스톡** 육교·아파트 계단 |
| 48~52 | "내려가는 게 더 힘든 이유입니다." | **스톡** 천천히 내려가는 발 |
| 52~53 | (무음) | `@black` |

보조 자막 마지막: `다음 편: 지팡이는 얼마나 도움이 될까`

## 화면 소재 계획

| 종류 | 개수 | 검색어 / 프롬프트 | 비용 |
|---|---|---|---|
| 스톡 | 6 | `hiking downhill`, `climbing uphill trail`, `stairs feet closeup`, `subway stairs`, `pedestrian overpass stairs`, `walking down stairs slowly` | **0** |
| AI | 1 | 검은 배경, 반투명 인체 무릎 관절, 하중에 따라 청록→주황→빨강으로 달아오름, 9:16 | 27.5cr |
| 단색 | 1 | `@black` | **0** |

**AI 클립 1개를 세 구간(17초·23초·33초)에서 나눠 씁니다.** 색이 달아오르는
과정이 담긴 한 클립이면 충분하고, 자막과 나레이션이 바뀌니 다른 컷으로 읽힙니다.

## 왜 이 구성이 나은가

**스톡이 많아서 좋은 게 아니라, 몸 속 장면이 딱 한 번이라 강해집니다.**
실사만 계속 나오다가 갑자기 몸 안으로 들어가는 순간이 이 채널의 정체성입니다.
40초 내내 인체 모델이 떠 있으면 그 순간이 사라집니다.

## 검수 체크

- [x] 첫 10초에 숫자가 없는가
- [x] 첫 문장이 시청자가 겪은 상황인가
- [x] 장소가 구체적인가 (계단 → 지하철 출구 계단)
- [x] 몸의 느낌으로 말했는가 (부담 → 시큰함)
- [x] 숫자가 4개 이하인가 (261, 316, 346 → 3개)
- [x] 마지막이 일상으로 돌아왔는가
- [x] 진단·처방으로 넘어가지 않았는가
